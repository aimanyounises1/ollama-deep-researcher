## How to Generate Similar Reports

### Using the Command Line

```bash
python run_graph_3.py --debug "Your research question here"
```

### Using the Web Interface

1. Start the application:
   ```bash
   python app.py
   ```

2. Navigate to `http://localhost:3000`

3. Enter your research query and click "Research"

4. The system will:
   - Analyze your query
   - Perform multi-iteration research
   - Generate knowledge graphs
   - Track citations
   - Produce a comprehensive report

## Customizing Reports

### Configure Research Depth

Edit `.env` to adjust research parameters:

```bash
# Maximum research iterations
OLLAMA_MAX_WEB_RESEARCH_LOOPS=3

# Include web search
OLLAMA_INCLUDE_WEB_SEARCH=true

# Generate knowledge graphs
OLLAMA_GENERATE_KNOWLEDGE_GRAPH=true

# Track citations
OLLAMA_TRACK_CITATIONS=true

# Maximum web search results per iteration
OLLAMA_MAX_WEB_SEARCH_RESULTS=5
```

### Export Formats

## Tips for Better Results

1. **Be Specific**: More specific queries yield more focused results
   - Good: "How to implement JWT authentication in FastAPI"
   - Less Good: "Authentication in Python"

2. **Include Context**: Mention your use case or constraints
   - "How to deploy Python microservices with limited resources"

3. **Ask Follow-up Questions**: Run iterative research for deeper insights
   - First: "What is GraphQL?"
   - Then: "How to implement GraphQL subscriptions in Node.js"

4. **Use Technical Terms**: The system understands domain-specific terminology
   - "CAP theorem in distributed systems"
   - "CQRS pattern implementation"
